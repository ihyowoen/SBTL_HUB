## CP17 정정: URL 문서 식별 충돌

CP17 최초판은 방위사업청의 URL 쿼리 `bbsSeq=443`을 문서 ID로 과신하여 **행 1297(`docSeq=59315`)**과 **행 1309(`docSeq=59289`)**를 하나의 기사 관측 묶음으로 잘못 합쳤다. 같은 게시판 번호만으로 사건/문서 동일성을 판단할 수 없다.

정정본은 `docSeq`와 기타 추적 목적이 아닌 쿼리를 URL 정체성에 포함하고, 독립 QC에도 **이 두 문서가 분리되는지** 검사를 추가했다. 정정된 CP17 원본 스냅샷의 1,231개 미판정 Source ID는 **안전한 출처 검토 단위 1,130개**, 반복 출처 관측 감소 **101개**로 재구성된다. **1,130은 확정 사건 수가 아니며, 101은 사건 중복 확정 건수가 아니다.** CP18은 이 중 6개 Source ID를 정식 처분했으므로 이후 잔여 정식 미판정은 1,225개다.

CP17 최초 보고서·워크시트의 1,129개 단위 등 이전 집계는 **이 정정본으로 대체**한다. 원본 URL·1,330개 Source ID는 삭제·병합·재번호화하지 않았다.
